- Spec 0048 wave 5 (plan 0048 P11): the vendored `vendor/cortex`, `vendor/saga` and `vendor/soma` contracts (55 files) are gone; `crates/uas-engine/build.rs` reads `.contracts/` from `make fetch-contracts` (the pinned fetch) and a missing contract fails the `cortex-grpc` build with `run cargo xtask fetch-contracts`; `vendor/leanspec` stays with its LICENSE. No CI job builds `cortex-grpc` today and the runners hold no credential for the private contract repos, so a CI fetch is deferred until one does.

### Fixed
- `cargo xtask pin-check` fails closed on a malformed `| Crate | Version |` row (an empty crate name, a version that is not `X.Y.Z` or `X.Y.Z+build`, or unequal crate and version counts) and names the spec line, and `xtask` walks up from the working directory to find the repository root instead of using a compiled-in path (spec 0004 D3).
- Spec 0051 wave 2 (plan 0051 P4): the lefthook commit hook fails closed when the gitleaks binary is missing, printing the install hint, instead of skipping the secret scan with a notice; AGENTS.md says lefthook runs gitleaks.
- Spec 0051 wave 1 (plan 0051 P1, P2): guard-main-push now denies `git -C <dir> push` to main, every push to `development` (including force and `HEAD:` forms) and a bare `git push` while main or development is checked out, and no longer denies a branch name that merely contains `main`; after the critic round it also covers `HEAD` on a protected branch, quoted refs, `NAME=value` and `sudo` prefixes, `--all`, `--mirror` and `--repo=` (31 test rows; `--repo origin` with a space is not parsed); ci-gate wraps `make check` in `timeout -k 10 840` and fails closed with a one-line reason on a timeout (exit 124 or 137) or any failure, so a slow or hung check never lets a push through (`CI_GATE_TIMEOUT` for tests).
- The cas-ebpf clamp test measures against its own nice value, so a niced parent no longer fails the control, and it fails when it runs at nice 19.
- The wave readiness pre-read runs `timeout -k 5 30 gh pr view`, so a hung `gh` cannot block a step. Exit 124 or 137 records nothing; exit 125, 126 or 127 from `timeout` is an executor error (spec 0025 D15).
- `cas-cli`: `cas harness run` makes `--evidence` optional, defaults dry runs to heuristic evidence, and rejects claiming verified or reported evidence when simulating execution (CER-2671).
- `cas-domain`: deserializing a `Slot`, `Lease`, `Budget` or `Envelope` now runs the same checks as the constructors. Before, JSON could build a `Leased` slot with no worktree, a lease that ends before it begins, a zero budget, or an envelope with a bad id.
- `cas-ebpf`: a tracked worker that runs `unshare -Upf --fork` is no longer lost to the audit. When the namespace helper fails, the probes fall back to the global tgid with `ns_pid` 0, so the nested task stays in `TRACKED_PIDS`, its exec is audited, its children are tracked and its exit evicts it. `cas-ebpfd` never re-clamps `ns_pid` 0, refuses `track` and `untrack` of pid 0, and refuses any peer, root included, whose pid namespace differs from its own. Tests now use fixtures with `ns_pid` different from `pid`, and the exit test asserts on `TRACKED_PIDS` by global pid (CER-2773, spec 0014 D12).
- cas-ebpf reads the sched tracepoint field offsets from tracefs at load (spec 0014 D13, T16). Fork `child_pid` is at offset 20 on kernel 6.18, not 44, so the fork probe read the wrong bytes there. A format file that breaks the layout rules stops the load before any attach.
- `cas-ebpf` tracefs load refuses a `filename` field typed `__data_locx`. The check matches the exact `__data_loc` token (spec 0014 D13).
- Rollback runs every compensator. A failed compensator leaves a failed receipt, the rest still run, and rollback then returns `CompensationIncomplete` with all receipts (spec 0009, spec 0024).
- A workflow compensator that returns `Err` no longer leaves the session at `Compensating`. `fail_activity` keeps its receipt, ends the log with `SessionFinished` in `Failed`, and returns `CompensationIncomplete` (spec 0009, CER-2785).
- `cas wave flow` writes no empty flow for a wave whose only step moved, names `--out-dir` in its header, and sets `agent = "auto"` on each shim step (spec 0025 P9b).
